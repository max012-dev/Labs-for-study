# Лабораторная работа 1. Первые программы на Python

## Инструкция по запуску
Все программы запускаются из терминала, находясь в папке `lab1`:

Откройте командную строку (нажмите Win+R, введите cmd и нажмите Enter).
Перейдите в папку, где находится файл программы, командой cd путь_к_папке.
Запустите программу: python имя_файла.py.

Альтернативный вариант: через IDLE
1. Запустите программу IDLE (устанавливается вместе с Python).
2. В верхнем меню выберите File → Open и откройте ваш файл (например, variant.py).
3. Откроется окно с кодом. Нажмите клавишу F5 на клавиатуре (или в верхнем меню выберите Run → Run Module).
4. Программа запустится в соседнем интерактивном окне

Также можно запустить программу через интегрированную среду разработки (IDE)

В VS Code:
Установите официальное расширение Python.
Откройте папку с проектом (File → Open Folder).
Выберите интерпретатор Python в строке состояния (щелкните по версии Python).
Откройте файл программы и нажмите Run на панели редактора или запустите через встроенный терминал командой python имя_файла.py.
 
В PyCharm:
Создайте или откройте проект.
Укажите нужный интерпретатор в настройках (Settings → Project → Python Interpreter).
Откройте файл и нажмите Run на панели инструментов (Shift + F10).

### 5. Проверка `variant.py` (Магазин для животных)

* **Тест 1 (Базовый с расчетом скидки 0%):**
  * *Входные данные:* Позиция 1 = 3 ед. по `12.50` руб. (37.50), Позиция 2 = 2 ед. по `20.00` руб. (40.00). Скидка = `0`%. Доставка = `10.00` руб. Внесено = `100.00` руб.
  * *Ожидаемый результат:* Товары без скидки = `77.50`, Скидка = `0.00`, Товары со скидкой = `77.50`, Итого = `87.50`, Количество = `5`, Сдача = `12.50`.
  * *Фактический результат:* Полное совпадение.

* **Тест 2 (Проверка добавленной скидки 10%):**
  * *Входные данные:* Позиция 1 = 3 по `12.50` (37.50), Позиция 2 = 2 по `20.00` (40.00). Всего товаров = `77.50`. Скидка = `10`%. Доставка = `10.00`. Внесено = `100.00`.
  * *Ожидаемый расчет вручную:* 
    * Скидка в рублях: 77.50 * 0.10 = `7.75` руб.
    * Стоимость товаров со скидкой: 77.50 - 7.75 = `69.75` руб.
    * Общая сумма (с доставкой): 69.75 + 10.00 = `79.75` руб.
    * Сдача: 100.00 - 79.75 = `20.25` руб.
  * *Фактический результат:* Программа вывела скидку 7.75 руб., общую сумму 79.75 руб. и сдачу 20.25 руб.

* **Тест 3 (Нулевое количество одной позиции):**
  * *Входные данные:* Позиция 1 (Упаковки корма) = `0` ед., Позиция 2 (Игрушки) = `2` ед. по `20.00` руб. Скидка = `0`%. Доставка = `10.00` руб. Внесено = `50.00` руб.
  * *Ожидаемый результат:* Стоимость 1 = `0.00`. Общая сумма = `50.00`. Сдача = `0.00`. Количество = `2`.
  * *Фактический результат:* Упаковки корма посчитались как 0.00 руб., итоговая сумма совпала.

* **Тест 4 (Нулевая доставка):**
  * *Входные данные:* Позиция 1 = 3 по 12.50, Позиция 2 = 2 по 20.00. Скидка = 0%. Доставка = `0.00` руб. Внесено = `100.00` руб.

  * *Фактический результат:* Доставка отобразилась как 0.00 руб., сдача рассчитана корректно.
