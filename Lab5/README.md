## 3. Контрольные вопросы

### 1. Почему строки в Python являются неизменяемыми (immutable)?
Строка — это неизменяемый объект. Это означает, что после создания строки в памяти компьютера её содержимое нельзя модифицировать напрямую (например, нельзя перезаписать отдельный символ по индексу: `text[0] = 'W'` вызовет ошибку `TypeError`). 

Любые операции трансформации (такие как `.lower()`, `.replace()`, `.strip()`) не меняют исходный объект, а создают и возвращают в памяти **абсолютно новую строку**. Неизменяемость обеспечивает безопасность данных и позволяет Python оптимизировать работу с памятью (например, через кэширование одинаковых строк).

### 2. В чём отличие слова от подстроки?
* **Слово** (в рамках данной работы) — это обособленная часть текста, выделенная с помощью метода `.split()`. Изначально оно отделено от других частей пробельными символами и может включать в себя прикреплённые знаки препинания (например, `"Анна,"`).
* **Подстрока** — это любая непрерывная последовательность символов, взятая из исходной строки. Подстрока может быть частью слова (например, `"ан"` в слове `"анна"`), целым словом или даже включать в себя несколько слов вместе с пробелами (например, `"на, ар"`).

### 3. Почему правила обработки пунктуации нужно задавать до написания программы?
Правила обработки знаков препинания критически влияют на алгоритмическую логику и строгость сравнений. Если не утвердить правила заранее, возникнут логические ошибки:
1. **При поиске палиндромов:** Строка `"А!"` без явных правил может быть ошибочно признана палиндромом, если алгоритм проигнорирует знак восклицания, или отклонена, если знак будет учитываться (в нашей работе пунктуация учитывается, поэтому `"а!" != "!а"` — это не палиндром).
2. **При подсчёте длин слов:** Слово `"Анна,"` имеет длину 5 символов из-за запятой. Если не очистить её с помощью `.strip()`, программа посчитает длину неверно и слово с чётной основой (4 буквы) не попадёт в выборку Варианта 14.

## 4. Сравнение алгоритмов проверки палиндрома
1. **Решение через срез (`text[::-1]`):** 
   * *Плюсы:* Лаконичный, легко читаемый код, написанный в декларативном стиле. Быстро работает на уровне языка.
   * *Минусы:* Требует выделения дополнительной памяти для хранения полной копии перевёрнутой строки.
2. **Решение через цикл (`for` до середины строки):**
   * *Плюсы:* Экономит память (O(1) по памяти), так как не создаёт дубликат строки, а сравнивает символы по индексам `i` и `n-1-i` напрямую. Может завершить работу досрочно (`break`), если несоответствие обнаружено в самом начале.
   * *Минусы:* Код более громоздкий, скорость итераций чистого цикла `for` в Python на огромных строках может уступать встроенному оптимизированному срезу.
