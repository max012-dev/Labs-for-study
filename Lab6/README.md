## Инструкция по запуску
Все программы запускаются из терминала, находясь в папке `lab6`:

Откройте командную строку (нажмите Win+R, введите cmd и нажмите Enter).
Перейдите в папку, где находится файл программы, командой cd путь_к_папке.
Запустите программу: python имя_файла.py.

Альтернативный вариант: через IDLE
1. Запустите программу IDLE (устанавливается вместе с Python).
2. В верхнем меню выберите File → Open и откройте ваш файл (например, variant.py).
3. Откроется окно с кодом. Нажмите клавишу F5 на клавиатуре (или в верхнем меню выберите Run → Run Module).
4. Программа запустится в соседнем интерактивном окне

Также можно запустить программу через интегрированную среду разработки (IDE)

В VS Code:
Установите официальное расширение Python.
Откройте папку с проектом (File → Open Folder).
Выберите интерпретатор Python в строке состояния (щелкните по версии Python).
Откройте файл программы и нажмите Run на панели редактора или запустите через встроенный терминал командой python имя_файла.py.
 
В PyCharm:
Создайте или откройте проект.
Укажите нужный интерпретатор в настройках (Settings → Project → Python Interpreter).
Откройте файл и нажмите Run на панели инструментов (Shift + F10).

## 2. Контрольные вопросы

**1. Сохранение исходного списка в задании №2?**
В коде программы исходный массив обрабатывается исключительно в режиме чтения. Все изменения происходят при добавлении элементов в новый изолированный список методом `append()`. Итоговый вывод обоих списков на экран подтверждает, что структура исходного массива не изменилась.

**2. В чём разница между append() и присваиванием по индексу [i]?**
* `items.append(value)` — динамически расширяет размер списка, вставляя элемент в самый конец структуры. Длина списка всегда увеличивается на 1.
* `items[i] = value` — осуществляет перезапись значения строго внутри уже существующей ячейки памяти с индексом `i`. Метод не меняет общую длину списка. Попытка обратиться к несуществующему индексу вызовет ошибку `IndexError`.

**3. В чём различие между функцией sorted() и методом списка .sort()?**
* `sorted(items)` — это встроенная глобальная функция. Она принимает список, создаёт его независимый дубликат, сортирует его и возвращает этот дубликат как результат. Исходный список остаётся неизменным.
* `items.sort()` — это метод класса `list`. Он выполняет сортировку элементов прямо внутри исходной структуры памяти («на месте»), безвозвратно меняя порядок элементов оригинального списка. Метод всегда возвращает значение `None`
