## Инструкция по запуску
Все программы запускаются из терминала, находясь в папке `lab1`:

Откройте командную строку (нажмите Win+R, введите cmd и нажмите Enter).
Перейдите в папку, где находится файл программы, командой cd путь_к_папке.
Запустите программу: python имя_файла.py.

Альтернативный вариант: через IDLE
1. Запустите программу IDLE (устанавливается вместе с Python).
2. В верхнем меню выберите File → Open и откройте ваш файл (например, variant.py).
3. Откроется окно с кодом. Нажмите клавишу F5 на клавиатуре (или в верхнем меню выберите Run → Run Module).
4. Программа запустится в соседнем интерактивном окне

Также можно запустить программу через интегрированную среду разработки (IDE)

Установите официальное расширение Python.

Отличие / от //

• / — это обычное деление. Всегда возвращает дробное число (float). 7 / 2 = 3.5.

• // — целочисленное деление. Отрезает дробную часть и округляет вниз (к ближайшему меньшему целому). 7 // 2 = 3, а -7 // 2 = -4.

Смысл остатка (%)

• % находит остаток, который не разделился нацело. Работает по железному правилу: a = (a // b) * b + a % b.

• Нужен, чтобы проверять четность (x % 2 == 0), откусывать последние цифры (x % 10) или «зацикливать» числа (как секунды в минуты: seconds % 60).

Почему :.2f не лечит неточность float

• Компьютер хранит float в двоичной системе. Дроби вроде 0.1 переводятся в бесконечные двоичные хвосты и округляются с микропогрешностью в памяти.

• Спецификатор :.2f — это просто маска для print(). Он округляет число только визуально на экране, чтобы пользователю было красиво. В самой переменной в памяти по-прежнему лежит неточное число, и в следующих вычислениях эта ошибка всплывет снова.
