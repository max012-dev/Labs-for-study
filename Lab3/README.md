## Инструкция по запуску
Все программы запускаются из терминала, находясь в папке `lab3`:

Откройте командную строку (нажмите Win+R, введите cmd и нажмите Enter).
Перейдите в папку, где находится файл программы, командой cd путь_к_папке.
Запустите программу: python имя_файла.py.

Альтернативный вариант: через IDLE
1. Запустите программу IDLE (устанавливается вместе с Python).
2. В верхнем меню выберите File → Open и откройте ваш файл (например, variant.py).
3. Откроется окно с кодом. Нажмите клавишу F5 на клавиатуре (или в верхнем меню выберите Run → Run Module).
4. Программа запустится в соседнем интерактивном окне

Также можно запустить программу через интегрированную среду разработки (IDE)

В VS Code:
Установите официальное расширение Python.
Откройте папку с проектом (File → Open Folder).
Выберите интерпретатор Python в строке состояния (щелкните по версии Python).
Откройте файл программы и нажмите Run на панели редактора или запустите через встроенный терминал командой python имя_файла.py.
 
В PyCharm:
Создайте или откройте проект.

Откройте файл и нажмите Run на панели инструментов (Shift + F10).

*Почему в minimum.py нельзя использовать min() и max()*

• Функции min() и max() скрывают внутреннюю логику перебора элементов и выполняют ветвление на уровне скомпилированного Си-кода.

• Цель работы — научиться самостоятельно управлять потоком выполнения программы, проверять граничные условия через базовые операторы if/elif/else и понимать, как процессор последовательно сравнивает регистры памяти.

*Разница между оператором = и ==*

• Оператор = — это оператор присваивания. Он вычисляет выражение справа и записывает результат в переменную слева (x = 5).

• Оператор == — это оператор сравнения. Он проверяет равенство двух значений и всегда возвращает логический тип данных True или False (x == 5).

*Опасность использования eval() в calculator.py*

• Функция eval() выполняет переданную строку как полноценный Python-код с правами текущего пользователя.

• Если пользователь вместо чисел введет вредоносный код (например, команду на удаление файлов), eval() беспрекословно выполнит ее, что создает критическую уязвимость в безопасности приложения.

*Особенность лексикографического сравнения строк*

• Строки сравниваются посимвольно слева направо по их кодам в таблице символов (Unicode), а не по числовому значению.
• Из-за этого выражение "10" < "2" возвращает True, так как первый символ "1" имеет меньший код, чем символ "2", независимо от длины строки.
