Все программы запускаются из терминала, находясь в папке `lab7`:

Альтернативный вариант: через IDLE
1. Запустите программу IDLE (устанавливается вместе с Python).

3. Откроется окно с кодом. Нажмите клавишу F5 на клавиатуре (или в верхнем меню выберите Run → Run Module).
4. Программа запустится в соседнем интерактивном окне

Также можно запустить программу через интегрированную среду разработки (IDE)

## Контрольные вопросы

### 1. Разница между возвратом (`return`) и выводом (`print`)
*   **`return`** — это инструкция языка, которая завершает выполнение функции и передает полученное значение *обратно в вызывающий код*. Это значение программа может сохранить в переменную, использовать в условиях (`if`) или передавать в другие математические вычисления.
*   **`print()`** — это встроенная функция, которая всего лишь отображает текстовые символы *на экране компьютера для человека*. Программа никак не может использовать напечатанные на экране символы для дальнейшей внутренней логики.

### 2. Разница между локальной переменной и параметром
*   **Параметр** — это переменная, которая указывается в круглых скобках при *объявлении* функции (например, `threshold`). Он выступает «входным портом» для данных, передаваемых функции извне при её вызове.
*   **Локальная переменная** создается *внутри* тела функции в процессе её выполнения (например, `divisor = threshold + 1` или `total = 0`). Она существует и доступна только внутри этой функции и автоматически удаляется из памяти сразу после завершения работы функции.
